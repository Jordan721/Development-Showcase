# The One Day Triathlon

A modern rebuild of an early academic website, reimagined as an arcade-inspired 24-hour game jam page.

## Highlights

- Responsive, accessible game-jam project page layout
- Arcade-style cover panel, stats sidebar, devlog section, and jam notes
- Randomized genre, mechanic, and wildcard challenge generator with 15,625 possible briefs
- Independently lockable challenge results
- Game-like roll, reveal, and lock animations
- Persistent 24-hour countdown using local storage
- Mobile navigation and reduced-motion support
- Reuse of the project's original photography with animated game-style overlays

Open `index.html` directly in a browser. No build step or dependencies are required.
