# The One Day Triathlon

A modern rebuild of an early academic website, reimagined as an interactive 24-hour game jam experience.

## Highlights

- Responsive, accessible single-page event design
- Project-story case study documenting the original concept and modern rebuild
- Randomized genre, mechanic, and wildcard challenge generator
- Independently lockable challenge results
- Persistent 24-hour countdown using local storage
- Mobile navigation and reduced-motion support
- Reuse of the project's original photography with a new visual direction

Open `index.html` directly in a browser. No build step or dependencies are required.
