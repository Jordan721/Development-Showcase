# Run Like A G.U.R.L Documentary Archive

A modern archival redesign of a student group project created for the Run Like A G.U.R.L documentary initiative.

## Project context

The original academic assignment recreated a discontinued WordPress website. Jordan Alexis built the website while other group members developed artwork and the final project documentation.

This revision reframes the work as an educational documentary archive rather than an active promotional or fundraising website. Original materials remain the property of Run Like A G.U.R.L and their respective creators.

## Highlights

- Responsive editorial layout built without a framework
- Accessible embedded media description
- Interactive, keyboard-navigable thematic explorer
- Historical context timeline
- Filmmaker profiles and archival image viewer
- Transparent before-and-after project case study
- No active donation, contact, or social-media integrations

Open `index.html` directly in a browser. No build step is required.
