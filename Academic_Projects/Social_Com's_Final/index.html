About This Project

What started as a class project has evolved into something much cooler! I created this social media mockup to explore what privacy-first networking could look like, wrapped in sleek, modern design.

Think of this as the "2.0" version - I've completely rebuilt it with modern web techniques and fresh ideas. Check out the wireframes to peek at the original beta concept!

From responsive layouts to smooth interactions and multiple pages, this project showcases what happens when you combine creativity with code.
