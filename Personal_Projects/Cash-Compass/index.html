PIPELINETRACK CONNECTION

Your opportunities

Import → review base pay → compare → use an estimate in your plan.

How does the connection work?

In PipelineTrack, open My Profile → Data Backup → Export to Cash Compass. Search and select jobs, then download the pay-planning JSON file. Import that file here. Review USD base pay and period before using estimates. Reimporting updates jobs by ID; absent jobs stay. This is a manual transfer, not automatic sync. Total compensation is reference only.
