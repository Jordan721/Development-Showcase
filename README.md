## 🤔 What's This All About?

Hey there! 👋🏾 Welcome to my **Development Showcase** — a carefully curated gallery of websites and interactive projects I've created over the years. This isn't just another boring portfolio site; it's a visual journey through my growth as a developer!

From classroom assignments to professional bootcamp projects, each piece tells a story of learning, experimentation, and problem-solving. I wanted to create something that not only displays my work but does it with **style** and **modern flair**! 🤩

## ✨ What Makes This Special?

### 🎯 The Features

## 🚀 Quick Start

Want to run this locally? It's super easy!

```bash
# Clone the repository
git clone https://github.com/Jordan721/Development-Showcase.git

# Navigate to the project folder
cd Development-Showcase

# Open in your browser
# Option 1: Double-click index.html
# Option 2: Use a local server (recommended)
npx serve
# or
python -m http.server 8000
```

Then visit `http://localhost:8000` and enjoy! 🎉

## 🌟 Features Deep Dive

### 🎭 Animation Toggle
Not a fan of moving backgrounds? No problem! Hit that toggle button and enjoy a peaceful, static experience. Your preference is saved too! 💾

### 🎨 Theme Color Picker
Click the palette button to open the theme panel! Choose from 8 beautiful preset colors (Purple, Blue, Emerald, Rose, Orange, Cyan, Pink, Yellow) or use the rainbow hue slider to pick any color you want. The entire site adapts — constellation particles, buttons, folder icons, project cards, and more! Your preference is saved to localStorage. 🌈

### 📊 GitHub Activity Feed
See what I've been working on! The site fetches my latest commits from this very repository using the GitHub API. Click any commit to see the full details on GitHub! 🔍

### 🧭 Smart Navigation
The floating navigation dots track your scroll position and highlight where you are. Click them to jump to any section instantly!

### 🎨 Glass Morphism Cards
Those beautiful, semi-transparent cards with blur effects? That's glass morphism, baby! Each project card has hover animations that make exploring feel interactive and fun!

### 🎮 Game Vault
A dedicated arcade-themed section for playable web games! Features retro CRT scanline effects, game preview GIFs, platform compatibility badges, and an "Origins" section with downloadable legacy versions and random nostalgic quotes about each game's history. Includes The Idea Space — an SMT-inspired demon compendium with fusion calculator, global search, and party builder.
