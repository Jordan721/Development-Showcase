About This Project

🎓

Year Up United App Dev Bootcamp

This project was originally created as part of my Year Up United Application Development Bootcamp capstone project. The assignment was to build a Java application that users could interact with through a command-line interface.

💡

My Creative Twist

I decided to take it a step further and convert the entire Java application into an interactive web-based kiosk experience! This showcases my ability to adapt and transform projects across different technologies and platforms.

⚙️

Technologies Used

Original: Java, Object-Oriented Programming, File I/O
Web Version: HTML5, CSS3, JavaScript, Animations, Responsive Design
